# SDK Product CRUD frontend

Standalone Angular 20 application foundation for the supplied BI packages.

## Local development

Run `npm start` and open `http://localhost:4200/`.

## Checks

- `npm test` runs the Vitest test suite.
- `npm run build` creates the production build.

The API client retains relative URLs so the development proxy added in a later task can target `http://localhost:5201`.
